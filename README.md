# My Finance Dashboard｜我的個人理財空間

一個使用 **React、TypeScript、Vite、Tailwind CSS** 建立的繁體中文個人理財網站。使用 Recharts 呈現互動式圖表，以 Zod 驗證資料。支援手機、桌面與深色模式，財務資料儲存在目前瀏覽器的 localStorage。

**沒有後端、登入、銀行 API、雲端資料庫、分析追蹤或自動部署。沒有設定 GitHub Pages。** GitHub 只用來存放程式碼；請將儲存庫維持為 Private。網站的本機財務資料不會自動寫入程式碼或 Git。

## Windows 新手：從安裝到開啟網站

### 1. 安裝工具

1. 到 [Node.js 官方網站](https://nodejs.org/) 安裝 **Node.js 24 LTS**，保留預設選項（包含 npm）。Node 22.12 以上也符合 Vite 要求；本版本以 Node 24 驗證。
2. 若要使用 Git，從 [Git for Windows 官方網站](https://git-scm.com/downloads/win) 安裝 Git。也可使用 GitHub Desktop 管理自己的私人儲存庫。
3. 關閉並重新開啟「終端機」或 PowerShell，輸入：

```powershell
node --version
npm.cmd --version
```

應看到版本號。若出現找不到命令，請重開終端機，或重新安裝並確認加入 PATH。

### 2. 取得程式碼

在程式碼已存入私人 GitHub 儲存庫後，可使用 GitHub Desktop 登入並 Clone `zhewei1010-NSYSU/Finance-Achievement`，或使用終端機：

```powershell
cd "$HOME\Documents"
git clone https://github.com/zhewei1010-NSYSU/Finance-Achievement.git
cd Finance-Achievement
```

私人儲存庫如要求登入，請完成 GitHub 的瀏覽器授權，**不要將密碼或 Token 貼進程式碼**。

如果是下載 ZIP：在 GitHub 按 Code → Download ZIP，解壓縮後進入包含 `package.json` 的資料夾。在該資料夾的檔案總管網址列輸入 `powershell`，按 Enter。

> 本專案若仍是雲端工作區的未提交檔案，必須先將程式碼提交、推送到自己的私人儲存庫，才能從另一台電腦 Clone 到這個版本。建立檔案不代表已推送 GitHub。

### 3. 安裝依賴（第一次或更新程式碼後）

```powershell
npm.cmd ci
```

請保留 `package-lock.json`，以安裝已鎖定的依賴版本。安裝需要網路；使用網站時不需要連接銀行或資料服務。

### 4. 啟動本機網站

```powershell
npm.cmd run dev -- --port 5173 --strictPort
```

在**自己的電腦**瀏覽器網址列輸入 `http://127.0.0.1:5173`。保留終端機開啟，停止時在終端機按 `Ctrl+C`。下次使用時進入同一資料夾，再執行這個啟動命令即可，不必每次安裝。

- 請持續使用相同瀏覽器、使用者設定檔及網址。`localhost` 與 `127.0.0.1` 是不同的儲存來源，不共用資料。
- `--strictPort` 會在連接埠被占用時停止，避免自動換網址後看似資料不見。請關閉先前開啟的開發伺服器再重試。
- `npm.cmd` 可避開 PowerShell 對 `npm.ps1` 的執行政策問題，不需要關閉系統安全政策。
- 如果出現 `ENOENT package.json`，表示目前不在專案根目錄，請先用 `cd` 切到包含 `package.json` 的資料夾。
- 伺服器只綁定 `127.0.0.1`，沒有開放外網、區網存取或手機連線。手機尺寸可先用桌面瀏覽器的開發者工具預覽。

### 5. 檢查正式建置（選用）

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173 --strictPort
```

`dist/` 是建置結果，不會自動部署。預覽使用另一個連接埠，因此與開發網址的本機財務資料分開；要帶入資料請使用 JSON 備份。不要直接雙擊 `dist/index.html`。

## 第一次使用

1. **帳戶管理**：已提供郵局、銀行日常、國泰投資、高銀基金與信用卡，也可新增自訂資產／負債帳戶。先將各帳戶餘額調整為自己的實際情況。
2. **儲蓄目標**：起始示例為郵局 NT$10,000，目標 NT$40,000，截止日 2026/12/31，完成 25%。可新增、編輯、刪除多個目標、設定連動資產帳戶及日期。
3. **收支紀錄**：登記收入、支出、轉帳，帳戶餘額會一起更新。實際每月收入／支出取自紀錄，不把規劃月薪當作已領薪水。
4. **理財規劃**：填實領薪資、生活費、孝親費、儲蓄與投資金額，再調整年齡、目標資產與假設報酬。先即時預覽，按「儲存理財規劃」後才會保留。
5. **財務健檢**：查看緊急預備金、規劃儲蓄率、負債、預算餘額、目標進度分析。
6. **資料與備份**：下載 JSON，妥善存放在程式碼資料夾之外。需要換裝置時再匯入。

所有金額以新臺幣整數輸入，單筆金額上限 NT$1,000,000,000,000。起始年齡 25 歲、目標年齡 30 歲、資產目標 100 萬、報酬率 3% 都是**可修改的示意值，不是你的個人資料**。其他預算預設為零。

### 避免重複計算信用卡支出

| 情境                   | 應選操作                     | 結果                               |
| ---------------------- | ---------------------------- | ---------------------------------- |
| 薪水入帳               | 收入 → 銀行帳戶              | 增加資產與當月收入                 |
| 現金／銀行付款         | 支出 → 資產帳戶              | 降低資產，記一次支出               |
| 信用卡消費             | 支出 → 信用卡                | 增加負債，記一次支出               |
| 繳信用卡費             | 轉帳 → 來源銀行 → 目的信用卡 | 同時減少資產與負債，**不再計支出** |
| 銀行轉郵局             | 轉帳 → 銀行 → 郵局           | 總資產不變，儲蓄目標同步更新       |
| 對帳或手動更新投資市值 | 編輯帳戶餘額                 | 調整目前餘額，不產生收支紀錄       |

負債以「還欠多少」的正數填寫。系統拒絕資產餘額不足、負數金額、超額還款、同帳戶轉帳與未來交易。刪除交易會反向調整餘額；若反向操作造成負數，會拒絕刪除，請先核對後續交易與手動對帳。已連結目標或交易的帳戶必須先解除關聯才能刪除。

### 儲蓄進度、日期與達成紀錄

- 進度為指定帳戶目前餘額 ÷ 目標金額，圓環最多顯示 100%。這些錢已算在資產中，**不會再把目標存款加到總資產**。
- 每月需要儲蓄＝尚差金額 ÷ 含本月在內的剩餘月份，向上取整；未達成且逾期時顯示「已逾期，請調整」。
- 預計達標日期以理財規劃的「每月儲蓄金額」估算所需完整月數，不是銀行交易預測。未設定月存額時不虛構日期。月末會取目標月份有效的最後一天；超過 100 年顯示無法近期達成。
- 多目標連結同一帳戶時，每個目標都讀取完整餘額，**不是獨立資金桶**。每個預計日期也是假設全部月存投入該目標，不能把多目標的預測視為同時達成保證。
- 一次操作讓目標首次達到 100% 時，顯示金色彩帶、存款金額及完成日期，並儲存紀錄。重新開啟不會強制播放；可從「完成紀錄」重看。
- 完成後餘額下降仍保留歷史成就，圓環反映目前餘額；編輯已完成目標也保留原達成日期與金額。若要新挑戰，請新增目標。刪除目標會一併移除該目標紀錄。
- 開啟系統「減少動態效果」時，彩帶動畫停用，完成訊息仍顯示。

### 指標的定義

- 淨資產＝所有資產餘額－所有負債餘額。
- 首頁每月儲蓄率＝（實際紀錄收入－實際紀錄支出）÷ 收入；無收入時顯示 `—`。支出超過收入時可為負數。
- 理財規劃儲蓄率＝每月儲蓄預算 ÷ 實領月薪；投資另列，不含在這個儲蓄率內。
- 可支配餘額＝實領月薪－生活費－孝親費－儲蓄－投資。
- 每月資產投入＝儲蓄＋投資，不代表實際投資獲利。
- 六個月緊急預備金＝（生活費＋孝親費）× 6。健檢的可動用金額只計郵局、銀行與自訂資產，排除投資及基金。
- 趨勢圖保留每天最後一次操作的真實餘額快照，沒有捏造歷史。回填舊日期的交易只調整現在餘額，不會回溯重建過往資產快照。
- 模擬以目前淨資產為基礎，每月底投入儲蓄與投資；只有新增投資按假設年利率換算月利率複利。另列 -2% 壓力情境及自訂報酬＋3%（最高 20%）情境，虛線為目標資產。**所有報酬都是假設、不保證報酬**，不含通膨、稅費、負債利息與現有資產報酬。

## 備份、還原與隱私

- 使用 `my-finance-dashboard.v1` localStorage key，每個瀏覽器／網址各自保存，**並未加密**。只有你使用的私人裝置較合適；任何能使用該瀏覽器的人都可能讀到資料。
- 清除網站資料、無痕模式結束、換瀏覽器或換網址可能造成資料無法讀取，請定期下載 JSON。
- 匯入僅接受完整 v1 備份、5 MB 以下，驗證欄位、型別、金額、日期、唯一 ID 及帳戶關聯。有效檔案先顯示摘要，按確認才取代，取消或格式錯誤不覆蓋原資料。
- 匯入及重設前會觸發目前資料的備份下載；**請確認瀏覽器未阻擋下載，重要資料請先手動備份**。匯入採完整取代，不合併；也不強制播放既有達成動畫。
- 本機資料損毀時不靜默覆寫：顯示警告並暫停自動儲存，可先下載原始內容，再匯入有效備份或明確重設。
- 儲存空間不足或被瀏覽器拒絕時，會顯示警告；變更暫留記憶體，請立即匯出，以免關閉後遺失。
- 請勿同時在多個分頁編輯；本版本沒有多分頁鎖定、同步或跨裝置同步。
- `.gitignore` 排除依賴、建置、測試產物、`.env` 與本程式產生的 `finance-backup*.json`。仍請不要將個人備份放進專案，任意改名的敏感檔案無法靠忽略規則自動辨識。

## 開發與測試

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd audit
```

瀏覽器測試需要先安裝 Playwright Chromium（獨立測試設定檔，不會操作你的日常瀏覽器財務資料）：

```powershell
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Playwright 會使用或自動啟動 5173 的本機開發伺服器。若已有伺服器，請確認它是這個專案。Linux 若已有 Chromium，也可指定執行檔：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

程式碼格式：

```powershell
npm.cmd run format:check
npm.cmd run format
```
